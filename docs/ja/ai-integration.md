# AI連携

このページの詳細な説明はまだ日本語に翻訳されていません。Sprintが作成する
AI向けのローカル指示ファイルと、対応するエージェントの使い方については、
英語版の[AI integration](../ai-integration)を確認してください。

人が将来のSprintを追加する場合は、通常はSprintの**Add Sprint**または
**Generate future sprint**を使います。生成されるスキルには、これらのUIを
操作できないAIエージェント向けに、安全な手動作成手順も含まれます。
エージェントは設定済みの期間と既存Sprintから次の番号と日付を計算し、重複を
検出し、既存ノートを上書きせずに追加します。ライフサイクル状態は次回の
Sprint同期で調整されます。
