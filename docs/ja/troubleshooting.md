# トラブルシューティング

このページの詳細な説明はまだ日本語に翻訳されていません。ファイルが作成されない、
ワークスペースを移動した、ボードが空になる場合の手順は、英語版の
[Troubleshooting](../troubleshooting)を確認してください。

Sprintを停止している間にワークスペースを移動した場合、自動同期は停止し、
復旧画面が表示されます。新しいVault内の相対パスを入力して
**Locate workspace**を選択してください。**Not now**を選択した場合、Vaultは変更されず、
Obsidianを次回起動するまで自動表示されません。
