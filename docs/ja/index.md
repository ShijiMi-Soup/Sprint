# Sprint

SprintはObsidianに自動スプリント計画とプロジェクト別のカンバンボードを
追加します。設定した周期でスプリントノートを作成し、未完了の作業を繰り越し、
Obsidian Basesでタスク、スプリント、Velocity、プロジェクトを確認できます。
