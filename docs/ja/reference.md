# リファレンス

日本語版リファレンスは準備中です。現在利用できる仕様、用語、設定、ビュー、
リセット手順については、英語版の[Sprint Reference](../REFERENCE)を確認してください。

日本語で確認できるインストール手順は[インストールガイド](../INSTALLATION_ja)に
まとめています。

## 最近の標準設定

- `Tasks.base`を開くと、最初に**Sprint planner**ビューが表示されます。
- Sprint plannerでは、プロジェクトごとの横方向のスイムレーンに、Backlogと
  各スプリントの列が表示されます。タスクを横にドラッグするとスプリントを、
  別のスイムレーンへドラッグするとプロジェクトを変更できます。斜めに移動した
  場合は両方が更新されますが、タスクの進行状態は変更されません。モバイルや
  キーボード操作では、各カードのSprintとProjectセレクターから再割り当てできます。
- 新しいワークスペースでは、現在のスプリントに加えて将来のスプリントを2件
  （次回と次々回）作成します。この件数はSprint設定から変更できます。
- コマンドパレットの**Open planner**は、Tasks Baseの標準ビュー設定に
  関係なく`Tasks.base#Sprint planner`を直接開きます。

## プロジェクトの並び順

ビュー設定の**Order project groups by**で、プロジェクトのスイムレーンを名前、
またはプロジェクトのPriorityで並べ替えられます。**Project group direction**で
昇順／降順を選択できます。Priorityがないプロジェクトと**No project**は末尾に
表示されます。

## 今後のカンバン設定

Sprint board、Current sprint、Next sprint、Sprint plannerで共通利用する
カンバンコンポーネントと、ビューごとの安全な**Group by**、**Order by**設定を
今後追加する予定です。グループ間の移動で編集できる対象は、テキスト、数値、
チェックボックス、日付／日時、リスト、タグ、リンクなどのノートプロパティに
限定し、数式、ファイル情報、タイトル、派生状態、アーカイブなどの計算済み・
プラグイン管理プロパティは読み取り専用にします。
